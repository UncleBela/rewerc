Welcome to sz-werc
==================

Werc renders Markdown when you request a page. Edit this file and refresh
in your browser to see your changes.

* Read [about this site](/about).
* Browse the [notes](/notes/).
* Open the [site map](/sitemap).

Adding pages
------------

Create `sites/werc-guide/example.md` to publish a page at `/example`.
Create `sites/werc-guide/section/index.md` for a section at `/section/`.
Keep private settings in `_werc/`.
